# dotfiles

My terminal setup for macOS and Linux: zsh, tmux, Neovim, git and CLI tools, installed per user with one script (no sudo, never upgrades tools, backs up what it replaces).

Forgot a key? `prefix ?` in tmux (`Ctrl+Space`, then `?`), `dotfiles-help` in a shell, or `Space` and wait in Neovim.

## Docs

1. [install.md](docs/install.md): macOS and Linux desktop, update, uninstall, troubleshooting.

5. [contributing.md](docs/contributing.md): adding keys, scripts and tools so the help stays in sync.
